<h2 align="center">◈ EroCore Web Studio</h2>

<div align="center">

**EroCore Web Studio**, işletmeler için modern ve profesyonel web deneyimleri geliştiren butik bir web stüdyosudur.

Hazır şablonlara bağlı kalmadan;

**strateji → tasarım → geliştirme → optimizasyon → yayına alma**

sürecini tek bir çatı altında yürütür.

<br>

Amacımız yalnızca bir web sitesi oluşturmak değil,
markanın dijital dünyadaki **ilk izlenimini güçlendiren bir vitrin** tasarlamaktır.

</div>

<!-- ============================ LOCAL DEVELOPMENT ============================ -->

<h2 align="center">🚀 Yerel Geliştirme</h2>

```bash
git clone https://github.com/EroCores/erocore-web-studio-teklif.git

cd erocore-web-studio-teklif
```

Projeyi herhangi bir statik HTTP sunucusu ile çalıştırabilirsiniz.

Örneğin VS Code üzerinde **Live Server** kullanarak:

```text
index.html → Open with Live Server
```

veya Python ile:

```bash
python -m http.server 8000
```

Ardından:

```text
http://localhost:8000
```

adresini açabilirsiniz.
